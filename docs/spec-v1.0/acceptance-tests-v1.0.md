## 不変条件

1. 純残高は有効な支払い負担額と有効な実送金だけから算出。
2. 割当と相殺は金額の原本合計を変化させない。
3. 同方向の実送金から割り当てた合計は、その実送金額を超えない。
4. 支払いに対する送金割当＋相殺はその相手負担額を超えない。
5. 1ユーザーが同時に所属するactiveペアは最大1。
6. 変更履歴は人間による訂正・取消・復元の前後を追跡できる。

## 追加で実装するプロパティテスト

- 登録順と事業日付が異なる場合も決定的に計算する。
- 再計算を2度行っても2回目で計算結果が変化しない（冪等な投影）。
- 金額合計の上限・BIGINTオーバーフローを防ぐ。
- 複数タスク同時実行でも二重送金記録・二重ペア所属を作らない。
